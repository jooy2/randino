randSentence ​

문장을 만들어 count개를 문자열로 돌려줍니다. 각 문장은 주어와 서술어로 이루어지며, 그 언어가 실제로 쓰는 방식으로 적힙니다. 한국어 명사에 붙는 조사, 이탈리아어 명사 앞의 관사, 독일어 동사가 지키는 두 번째 자리까지 그렇습니다. output: 'detail'을 주면 문자열 대신 사용한 구를 함께 알려 줍니다.

javascript
import { randSentence } from 'randino';

randSentence();
// ['The satin ranger dances in the plush harborside.']
dart
import 'package:randino/randino.dart';

randSentence();
// ['The satin ranger dances in the plush harborside.']
python
from randino import rand_sentence

rand_sentence()
# ['The satin ranger dances in the plush harborside.']

단어는 randWord가 뽑는 것과 같은 일상 어휘이며, 사람 이름은 쓰지 않습니다. 문장이 거기에 더하는 것은 문법입니다. 형태와 동사가 무엇을 어디에 세울지 정하는 방식은 문장에서 설명합니다.

문장에 담는 구의 개수 ​

shape는 문장에 구가 몇 개 들어갈지를 고릅니다. 예상 길이에 가장 가까운 옵션입니다. minLength와 maxLength가 글자 수를 정한다면 이쪽은 구의 개수를 정합니다.

javascript
randSentence({ language: 'en', shape: 'simple', count: 3 });
// ['The halftrack slides.', 'The pilsner is cold.', 'The blunt canoeing deepens.']

randSentence({ language: 'en', shape: 'detailed', count: 3 });
// ['At night, the oak spreads.', 'The wily steppe brightens quickly.', 'The sprig wilts in the wild sunspot.']

randSentence({ language: 'en', shape: 'complex', count: 3 });
// ['The cheerful naga shares the americano in the sandy steppe.', 'The crab counts the hockey in the planetarium.']
dart
randSentence(language: WordLanguage.en, shape: SentenceShape.simple, count: 3);
// [The halftrack slides., The pilsner is cold., The blunt canoeing deepens.]

randSentence(language: WordLanguage.en, shape: SentenceShape.detailed, count: 3);
// [At night, the oak spreads., The wily steppe brightens quickly.]

randSentence(language: WordLanguage.en, shape: SentenceShape.complex, count: 3);
// [The cheerful naga shares the americano in the sandy steppe.]
python
rand_sentence(language="en", shape="simple", count=3)
# ['The halftrack slides.', 'The pilsner is cold.', 'The blunt canoeing deepens.']

rand_sentence(language="en", shape="detailed", count=3)
# ['At night, the oak spreads.', 'The wily steppe brightens quickly.']

rand_sentence(language="en", shape="complex", count=3)
# ['The cheerful naga shares the americano in the sandy steppe.']

simple은 주어와 서술어뿐이고, detailed는 구가 하나 더 붙으며, complex는 둘 이상 붙습니다.

형태 고르기 ​

slots는 주어 옆에 어떤 구가 올 수 있는지를 지정하며, 그중 아무것도 쓰지 않는 형태는 빠집니다. 하나라도 쓰면 통과하므로, 둘을 적으면 그중 아무거나 나오고 선택은 우연에 맡깁니다.

javascript
randSentence({ language: 'en', slots: 'object', count: 3 });
// ['The earthworm warms the nightcap.', 'The timid sorcerer builds the corduroy.']

randSentence({ language: 'en', slots: 'place', count: 3 });
// ['At dawn, the monorail sways in the bronze galaxy.', 'The cosmos darkens in the lunation.']

randSentence({ language: 'en', slots: 'state', count: 3 });
// ['The saffron is vague.', 'The weekend is dark.', 'The resolve is obvious.']

randSentence({ language: 'en', slots: 'none', count: 3 });
// ['The pearly hummus cools.', 'The litter passes.', 'The restless sleigh departs.']
dart
randSentence(language: WordLanguage.en, slots: {SentenceSlot.object}, count: 3);
// [The earthworm warms the nightcap., The timid sorcerer builds the corduroy.]

randSentence(language: WordLanguage.en, slots: {SentenceSlot.place}, count: 3);
// [At dawn, the monorail sways in the bronze galaxy.]

randSentence(language: WordLanguage.en, slots: {SentenceSlot.state}, count: 3);
// [The saffron is vague., The weekend is dark., The resolve is obvious.]

// 빈 집합이 다른 두 패키지의 `'none'`에 해당합니다.
randSentence(language: WordLanguage.en, slots: {}, count: 3);
// [The pearly hummus cools., The litter passes., The restless sleigh departs.]
python
rand_sentence(language="en", slots="object", count=3)
# ['The earthworm warms the nightcap.', 'The timid sorcerer builds the corduroy.']

rand_sentence(language="en", slots="place", count=3)
# ['At dawn, the monorail sways in the bronze galaxy.']

rand_sentence(language="en", slots="state", count=3)
# ['The saffron is vague.', 'The weekend is dark.', 'The resolve is obvious.']

rand_sentence(language="en", slots="none", count=3)
# ['The pearly hummus cools.', 'The litter passes.', 'The restless sleigh departs.']

형태는 언어마다 다르므로 모든 요청에 답할 수 있는 것은 아닙니다. 독일어에는 object가, 러시아어에는 place가 없습니다. 둘 다 명사의 어미가 바뀌는 격을 요구하는데 단어 풀은 형태를 하나씩만 담기 때문입니다. 그런 요청이 오면 그 언어가 가진 형태 전체에서 뽑습니다. 길이 범위가 너무 좁을 때 오류 대신 가장 가까운 결과를 주는 것과 같습니다.

javascript
randSentence({ language: 'de', slots: 'object', count: 3 });
// ['Im Frühling blüht eine Chrysantheme noch.', 'Eine neue Träne bebt.', 'Ein Kefir kühlt.']
dart
randSentence(language: WordLanguage.de, slots: {SentenceSlot.object}, count: 3);
// [Im Frühling blüht eine Chrysantheme noch., Eine neue Träne bebt., Ein Kefir kühlt.]
python
rand_sentence(language="de", slots="object", count=3)
# ['Im Frühling blüht eine Chrysantheme noch.', 'Eine neue Träne bebt.', 'Ein Kefir kühlt.']

언어를 지정하지 않으면 답할 수 있는 언어가 그렇지 못한 언어보다 먼저 뽑힙니다.

수량과 금액 ​

형태가 담을 수 있는 부분이 둘 더 있고, 다른 부분과 똑같이 slots로 요청합니다. quantity는 숫자와 수량사가 붙은 명사구이고, money는 금액과 그 언어가 돈을 세는 단위입니다.

javascript
randSentence({ language: 'ko', slots: 'quantity', count: 2 });
// ['파란 문어가 녹차 6개를 줍는다.', '파리가 감주 6개를 굽는다.']

randSentence({ language: 'vi', slots: 'quantity', count: 2 });
// ['Kỹ sư hẹp lau 7 cái thư.', '4 chiếc xe nôi chạy.']

randSentence({ language: 'en', slots: 'money', count: 2 });
// ['The silversmith describes 1,000 dollars.', 'The hollow magistrate remembers 500 dollars.']
dart
randSentence(language: WordLanguage.ko, slots: {SentenceSlot.quantity}, count: 2);
// [파란 문어가 녹차 6개를 줍는다., 파리가 감주 6개를 굽는다.]

randSentence(language: WordLanguage.vi, slots: {SentenceSlot.quantity}, count: 2);
// [Kỹ sư hẹp lau 7 cái thư., 4 chiếc xe nôi chạy.]

randSentence(language: WordLanguage.en, slots: {SentenceSlot.money}, count: 2);
// [The silversmith describes 1,000 dollars., The hollow magistrate remembers 500 dollars.]
python
rand_sentence(language="ko", slots="quantity", count=2)
# ['파란 문어가 녹차 6개를 줍는다.', '파리가 감주 6개를 굽는다.']

rand_sentence(language="vi", slots="quantity", count=2)
# ['Kỹ sư hẹp lau 7 cái thư.', '4 chiếc xe nôi chạy.']

rand_sentence(language="en", slots="money", count=2)
# ['The silversmith describes 1,000 dollars.', 'The hollow magistrate remembers 500 dollars.']

수량을 세는 언어는 수량사가 있는 넷뿐입니다. 어떤 수량사를 쓸지는 명사의 부류가 정합니다. 생물은 마리, 탈것은 대, 나무는 그루입니다. 한국어와 일본어와 중국어는 숫자를 명사 뒤에 두고, 베트남어는 수량사까지 함께 앞에 둡니다.

언어수량금액
ko ja zh vi✅✅
en es it—✅
de ru——

영어와 스페인어와 이탈리아어는 수량을 세지 않습니다. 복수형 규칙을 적용하면 이 풀에서 12 sadnesses, 12 bacons, 12 goggleses가 나오기 때문입니다. 풀의 명사 대부분은 셀 수 없는 명사이고, 어느 것이 셀 수 있는지는 데이터 어디에도 적혀 있지 않습니다. 수량사가 있는 언어에는 그 문제가 없습니다. 슬픔 12가지는 열두 가지 슬픔이고, 추상명사를 셀 수 있게 만드는 것이 수량사이기 때문입니다.

독일어와 러시아어는 수량도 금액도 세지 않습니다. 금액은 목적어 자리에 서는데, 두 언어는 목적어 형태를 선언하지 않기 때문입니다. 명사가 제 어미를 바꾸는 격이 필요하다는, 목적어 형태를 두지 않은 것과 같은 이유입니다.

수량 명사구에는 관사도 수식어도 붙지 않습니다. the 12 red apples가 아니라 12 apples입니다. 천 단위 구분은 언어마다 다릅니다. 영어와 한국어와 일본어와 중국어는 ,를, 베트남어와 스페인어와 이탈리아어는 .을 씁니다.

숫자와 단위 사이도 언어마다 다릅니다. 한국어는 6개, 300,000원처럼 단위와 화폐를 숫자에 붙여 씁니다. 일본어와 중국어는 띄어쓰기가 없으니 마찬가지입니다. 베트남어와 영어와 스페인어와 이탈리아어는 6 con, 500 dollars처럼 띄어 씁니다.

날짜와 시각 ​

문장이 담을 수 있는 부분이 둘 더 있습니다. date는 어느 날인지, clock은 몇 시인지를 나타내며, 둘 다 그 언어가 쓰는 방식으로 적힙니다.

javascript

// ['2024년 5월 12일에 촉촉한 모래톱이 깊어지죠.', '비는 2027년 9월 19일입니다.']

// ['At 13:24, the sherbet remains.', 'The torrent is at 3:26.']

randSentence({ language: 'de', slots: 'date', count: 2 });

randSentence(language: WordLanguage.ko, slots: {SentenceSlot.date}, count: 2);

날짜는 숫자만큼이나 어순의 문제입니다. 2026년 9월 5일은 큰 단위부터 쓰고, ngày 5 tháng 9 năm 2026은 반대 순서로 쓰면서 각 부분 앞에 단어를 붙이며, 5. September 2026은 달을 이름으로 부르고 일 뒤에 마침표를 찍습니다. 언어마다 자기 형식을 선언하고, 달을 이름으로 부르는 다섯 언어는 열두 이름을 함께 적습니다.

둘 다 설 수 있는 자리가 둘입니다. 부사구로 서거나(2026년 9월 5일에 사자가 달린다, On September 5, 2026, the lion runs), 문장이 주어를 그것과 같다고 놓는 자리에 섭니다(면접은 11시 40분이다., The match is at 11:40.).

뒤쪽은 계사문이며, 동사도 상태도 없는 유일한 문형입니다. 계사는 다른 서술어와 똑같이 다룹니다. 주어가 속할 수 있는 부류를 선언하고(어느 날에 일어나는 것은 사건이지 사자가 아닙니다), 화계와 서법이 요구하는 형태를 취합니다. 그래서 한국어는 이다, 이야, 이에요, 입니다를 쓰고 이니?로 묻습니다.

계사가 어디에 서는지는 언어가 정합니다. 한국어와 일본어는 대상 끝에 붙여 쓰므로 11시 40분이다가 한 단어입니다. 영어와 중국어와 베트남어와 스페인어와 이탈리아어와 독일어는 앞에 단어 하나로 세우고, 그 구가 원래 달고 있던 전치사도 그대로 둡니다. ist am 5. März처럼 씁니다.

러시아어는 calendar를 선언하지 않으므로, 요청하면 다른 처리 불가 요청과 마찬가지로 가장 가까운 형태로 물러납니다. 러시아어는 주어를 어느 날과 같다고 놓을 때 단어가 아니라 줄표를 쓰는데, 줄표는 의문이나 화계에 따라 변하지 않기 때문입니다.

반드시 넣을 단어 ​

include에 적은 단어는 모든 문장에 한 번 이상 들어갑니다. 풀이 아는 단어는 제자리에 들어갑니다. 명사는 주어가 되고, 동사는 서술어가 되며, 부사는 방법을 나타내는 자리로 갑니다. 풀에 없는 단어는 명사로 씁니다.

문장의 종류 ​

이 뽑기는 고르지 않고 한쪽으로 기울어 있습니다. 실제 글이 그렇기 때문입니다. 평서문이 가장 많고 누군가 하는 말이 그다음이며, 의문과 감탄은 여섯 중 가장 드뭅니다. 종류를 직접 지정하면 그 종류만 나옵니다.

javascript
randSentence({ language: 'en', type: 'question', count: 2 });

화계 ​

style은 문장을 어느 화계로 쓸지 정합니다. 한국어의 화계 그대로 네 단계입니다.

값화계어떤 말투인가
'plain'해라체글의 목소리. 듣는 사람이 없습니다.
'casual'해체 (반말)가까운 사이에 하는 말.
'polite'해요체같은 거리에서 높여 말한 것. 넷 중 가장 다정합니다.
'formal'합쇼체높이되 거리를 둔 말.

지정하지 않으면 결과마다 하나를 뽑으므로, 두 번 호출하면 화계가 서로 다를 수 있습니다. 지정하면 그 결과의 모든 문장이 그 화계로 쓰입니다.

한국어 의문형은 어미가 하나가 아니며, 풀의 항목이 그 어미들을 함께 적습니다. 형태 풀은 평서형과 자리를 맞춰 저장되므로 지정한 단어를 자리로 찾아 바꿀 수 있고, 한 항목이 |로 여러 어미를 담습니다. 달리니|달리나|달리는가는 동사 하나의 세 가지 어미이고, 문장마다 그중 하나가 뽑힙니다.

일본어는 두 단계뿐이라 네 단계에 나누어 맞춥니다. 'casual'은 보통체이고 'polite'와 'formal'은 둘 다 走ります입니다. 묻는 일은 어느 화계에서든 か가 맡습니다. 동사의 일부가 아니라 형태의 꼬리이기 때문입니다.

나머지 일곱 언어는 어느 화계에서도 같은 문장을 씁니다. 스페인어와 이탈리아어와 독일어와 러시아어에는 T–V 구분이 있지만 그것은 2인칭의 일이고, 여기 문장은 전부 3인칭입니다. el león corre는 상대가 누구든 같습니다. 영어에는 그런 형태가 아예 없습니다. 그래서 이 일곱은 화계를 선언하지 않으며, style은 아무것도 바꾸지 않습니다.

중국어는 낫표가 아니라 굽은 따옴표를 씁니다. 이 풀은 간체자로 쓰여 있고, 가로쓰기 간체 중국어는 “”를 씁니다. 「」는 대만과 홍콩의 것입니다. 독일어는 아래에서 열고 위에서 닫기 때문에 짝이 대칭이 아닙니다.

인용 표지는 붙지 않습니다. …라고 그는 말했다를 쓰려면 말한 사람과 말하는 동사가 있어야 하는데, 사람은 includeName이 붙여 주지만 말하는 동사는 아홉 언어 어느 풀에도 없습니다. 돌려받는 것은 대사 자체이고, 누가 말했는지는 담기지 않습니다.

한 결과에 여러 문장 ​

sentences는 결과 하나에 문장을 여러 개 담습니다. 결과는 문자열 하나이고, 문자열이 몇 개인지는 count가 정합니다. 담기는 문장들은 따로 뽑은 것이 아니라 같은 화제를 이어 가는 이야기입니다.

randSentence(language: WordLanguage.ko, sentences: 3);

#  'The temperance remains in the avalanche. Later the temperance gathers. It lingers once more.']

rand_sentence(language="ko", sentences=3)
# ['수상한 단술이 익는다. 하지만 옅은 단술이 식는다. 순진한 단술이 식는다.']

화제는 첫 문장이 정합니다. 뒤따르는 문장은 그 주어를 다시 부르거나, 그 자리에 대명사를 세우거나, 같은 부류의 다른 명사를 뽑습니다. 생물로 시작한 문단이 중간에 개념으로 새지 않는다는 뜻입니다. 접속사(But, 하지만, そして)로 시작하기도 합니다.

주어가 사람 이름일 때는 다릅니다. 민준으로 시작한 문단은 이름을 다시 부르거나 그 자리에 대명사를 세울 뿐, 같은 부류의 다른 사람을 뽑지 않습니다. 그랬다가는 문단이 도중에 다른 사람 이야기가 되기 때문입니다.

장면도 유지합니다. 첫 문장이 부른 장소에서 나머지 문장이 벌어지고, 다루던 사물도 그대로 이어집니다. 뒤 문장은 관사와 수식어를 새로 쓰므로 안개 나루터에서가 나루터에서가 되기는 해도 금고에서가 되지는 않습니다.

어투도 처음 것을 지킵니다. 서술로 연 문단에는 대사가 섞이지 않고, 인용으로 연 문단은 대사 사이에 서술이 들어갑니다. 한 사람이 내리 네 마디를 하면 그동안 벌어진 일이 통째로 빠지기 때문입니다. 사이에 들어가는 서술은 묻지 않고 말합니다. 물으면 두 사람뿐인 장면에 제3의 목소리가 끼어들게 됩니다.

접속사는 앞 문장에 대해 무엇을 주장하는지 표시해 두고 씁니다. 네 종류 가운데 시간이 흘렀다, 하나 더 있다, 그것과 반대다에 해당하는 셋은 어떤 문장 뒤에도 올 수 있습니다. 나머지 하나는 다릅니다. 그러므로, 그래서, so, だから는 이 문장이 앞 문장에서 비롯된다고 말하므로, 두 문장이 같은 것을 다루고 이 문장이 묻는 대신 말할 때만 쓸 수 있습니다. 프레첼 이야기 뒤에 그러므로 금빛 하이볼이 식죠?가 오면 아무것도 뒤따르지 않는 결과가 됩니다.

주장한국어영어일본어
하나 더그리고, 게다가and then, besidesそして, また
시간이 흘렀다이윽고, 마침내meanwhile, laterやがて, その後
그것과 반대하지만, 그러나but, howeverしかし, けれども
그래서그래서, 그러므로so, thereforeだから, つまり

언어는 자기가 쓸 수 있는 종류만 선언합니다. 독일어에는 시간을 나타내는 접속사가 없습니다. dann과 danach는 부사인데, 부사가 첫 자리에 서면 정동사가 자리를 옮기므로 절을 열 수 있는 것은 등위접속사 다섯 개뿐입니다.

한 문단은 같은 것을 두 번 하지 않습니다. 바로 앞 문장과 같은 종류는 되풀이될수록 확률이 낮아지므로 의문문이 줄줄이 이어지다 저절로 끊깁니다. 동사 무리는 한 바퀴 다 쓰고 나서야 다시 쓰므로 네 문장 중 셋이 같은 서술어로 끝나는 일이 없습니다. 사람 이름은 한 번 부르고 나면 한동안 부르지 않고, 새로 뽑는 주어는 부류 전체가 아니라 화제와 같은 테마에서 주로 나옵니다. 같은 접속사나 감탄사로 두 문장을 여는 일도 없습니다.

대명사를 어떻게 쓸지는 언어마다 다릅니다. 영어는 it을 쓰고, 한국어와 일본어와 중국어와 스페인어와 이탈리아어는 두 번째 문장에서 실제로 그러듯 주어를 생략합니다. 독일어와 러시아어는 명사의 성에 따라 고릅니다. 사람을 가리킬 수 없는 대명사만 있는 언어는 대신 화제를 다시 부릅니다. 영어의 he와 she는 단어 풀에 없는 성을 요구하고, 그것과 それ와 它와 nó는 무생물을 가리키기 때문입니다.

이름은 예외입니다. 성별을 지닌 주어는 이름뿐이기 때문입니다. Philip counts the prime. He forgets it in the supernova.처럼, the locksmith였다면 다시 부를 수밖에 없던 자리에 영어는 he를 세웁니다. 성별 대명사가 없는 언어는 그대로여서, 한국어는 사람을 두고 그것이라 하는 대신 주어를 생략합니다.

길이 범위는 문장 수와 무관하게 문자열 전체를 가리킵니다. 어느 문장을 뽑기 전에 범위를 나눠 갖고, 남는 몫은 마지막 문장이 가져갑니다.

javascript
randSentence({ language: 'ko', sentences: 3, minLength: 40, maxLength: 55 });

dart
randSentence(language: WordLanguage.ko, sentences: 3, minLength: 40, maxLength: 55);
// [반달이 함께 깊어진다. 그리고 별똥별이 역에서 물든다. 아침에 그것이 조용해진다.] // 45자

include에 적은 단어는 첫 문장에 들어갑니다. 문장마다 한 번씩이 아니라 결과마다 한 번씩 넣기 위해서입니다. sentences는 RAND_SENTENCE_COUNT_MAXrandSentenceCountMaxRAND_SENTENCE_COUNT_MAX인 10으로 제한됩니다.

사람 이름 ​

다른 생성기는 사람 이름을 일부러 피합니다. 닉네임을 사람 이름으로 만들지 않는다는 규칙이 이름과 단어를 갈라 둔 이유입니다. 문장만 예외입니다. includeNameincludeNameinclude_name은 문장에 사람이 설 자리가 있을 때 생성한 이름을 씁니다.

지정하지 않으면 결과마다 절반의 확률로 정합니다. 문장 단위가 아니라 결과 단위인 것은, 한 문단에 사람이 나오거나 나오지 않거나 둘 중 하나이기 때문입니다. 직접 지정하면 그 값이 그대로 쓰입니다.

javascript
randSentence({ language: 'en', includeName: true, count: 3 });
// ['Callum drinks the round rye.', 'Gavin crawls.', 'Veronica paints the plunger neatly.']

randSentence({ language: 'ko', includeName: true, count: 3 });
// ['소한이 날아오른다.', '종현이 심벌즈를 판다.', '은영이 어슬렁댄다.']

randSentence({ language: 'es', includeName: true, count: 3 });
// ['Hilario imagina la duda.', 'Adrián calienta la uva redonda.', 'Santiago rueda.']
dart
randSentence(language: WordLanguage.en, includeName: true, count: 3);
// [Callum drinks the round rye., Gavin crawls., Veronica paints the plunger neatly.]

randSentence(language: WordLanguage.ko, includeName: true, count: 3);

rand_sentence(language="es", include_name=True, count=3)
# ['Hilario imagina la duda.', 'Adrián calienta la uva redonda.', 'Santiago rueda.']

쓰이는 것은 성 없는 이름 하나입니다. 명사구가 아니라서 관사도 수식어도 붙지 않고, 한국어 조사는 다른 단어와 똑같이 이름의 마지막 글자를 보고 고릅니다(소한이, 은영이). 이름은 뽑을 때 정해진 성별을 그대로 지니고 있어서, 스페인어와 이탈리아어와 러시아어의 서술 형용사가 거기에 맞춰 굴절합니다. Celeste è affamata 옆에 Ivano è raro가 나오는 이유입니다. 이름은 어느 단어 풀에도 없으므로 생성기가 성별을 읽어 낼 곳이 이것밖에 없습니다.

이름은 사람이 설 수 있는 자리에만 섭니다. 이 옵션을 켜면 주어가 사람을 가리키는 테마로 좁혀지므로 문장에 이름을 둘 자리가 생깁니다. 직접 지정한 theme이 우선이며, 그때는 이름이 쓰이지 않습니다.

javascript
randSentence({ language: 'en', theme: 'animal', includeName: true, count: 2 });
// ['The wildebeest is lazy.', 'Yesterday, the moose stops.']
dart
randSentence(language: WordLanguage.en, theme: WordTheme.animal, includeName: true, count: 2);
// [The wildebeest is lazy., Yesterday, the moose stops.]
python
rand_sentence(language="en", theme="animal", include_name=True, count=2)
# ['The wildebeest is lazy.', 'Yesterday, the moose stops.']

SentenceDetail.names는 결과에 쓰인 이름을 알려 줍니다. 주어가 이름이면 theme: nulltheme: nulltheme=None입니다. 이름은 어느 테마에도 속하지 않기 때문입니다.

쓰든 쓰지 않든 22 KB가 늡니다

이 옵션은 사람 이름 풀에 손을 대는데, 동기 API에는 동적 import로 숨길 자리가 없습니다. 그래서 randSentence를 포함하는 번들은 이름 풀도 함께 포함합니다. esbuild로 randSentence만 번들하고 gzip한 결과는 이전 122.5 KB, 이후 144.5 KB로 +22.0 KB, +18%입니다. 문장 생성기는 이미 단어 풀 전체를 들고 있고 그것이 110 KB이며, 이름 풀은 그 옆의 22 KB입니다.

이름을 쓸 일이 없고 번들 크기가 중요하다면 randSentence를 가져오지 않는 것 외에 방법이 없습니다.

javascript
randSentence({ language: 'en', theme: 'animal', count: 3 });

dart
randSentence(language: WordLanguage.en, theme: WordTheme.animal, count: 3);

python
rand_sentence(language="en", theme="animal", count=3)
# ['The hippo sleeps in the starburst.', 'The sparrow approaches in the lightyear.']

지어낸 단어, 실제 문법 ​

realism은 단어가 어디서 오는지만 정합니다. 조사도 관사도 형태도 그 언어의 것이므로, 지어낸 단어로 된 문장도 문법은 그대로입니다.

javascript
randSentence({ language: 'ko', realism: 'invented', count: 3 });
